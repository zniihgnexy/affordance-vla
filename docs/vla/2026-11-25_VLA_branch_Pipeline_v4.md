## 1. 一句话

在 RoboCasa365 的仿真厨房里训练一个 VLA。它从一段画面判断任务做到哪一步、下一步和哪个物体交互；交互 map 给出在哪里碰、朝哪个方向；动作被训练成服从这个计划。

论点不变：affordance 只有在动作被训练成服从它时才有用。v4 加的是：由理解来决定 affordance 计划指向谁。

## 2. 和 v3 相比改了什么

| 项 | v3 | v4 |
|---|---|---|
| 环境 | LIBERO（桌面），零样本测 LIBERO-PRO | RoboCasa365 的厨房为主；LIBERO 和 LIBERO-PRO 保留，用来接上已有结果 |
| 任务类型 | 抓放 | 原子任务：抓放、开抽屉、开柜门、旋钮；再加几步连起来的组合任务 |
| 交互 map | 抓取的接触位置和夹爪闭合方向 | 推广到抽屉把手、柜门把手、旋钮，并加一项“碰到之后往哪个方向动”【设计】 |
| 理解 | 没有；语义门控只在单帧里按指令挑物体 | 新增一块：读最近一段画面和指令，回答当前是第几步、下一个交互目标是什么 |
| 谁来挑目标 | 指令 | 理解给出的“下一个交互目标”【设计】 |
| 同类新实例 | 3 种 mug 加缩放的 mug | RoboCasa 留出的实例：mug 27 个，bowl、cup 各 22 个 |
| 把 map 搬到新实例 | 最近点 | 最近点和 NDF 两种，对比后定 |
| 训练规模 | 冻结 VLM 的诊断规模，1 个训练种子 | 第 1 步：VLM 加 LoRA，和动作头、我们的模块一起训，单卡（项目负责人 11-26，7A）。主结果的全量微调、每个结果至少 3 个训练种子，留到有多卡算力时 |
| 算力 | 按一台 8×A6000 排 | 现在按一张 48 GB 的卡做（7A）。全量微调单卡放不下（第 0 步 ② 实测），要多卡，见第 7 节 |

不变的：VLM 是 starVLA 的 Qwen3-VL-4B；模型只做 2D 图像上的 map 加深度；仿真里的真值只用来生成标签和做评测，测试时不输入模型。**改了的（11-26）：** 动作头从 QwenPI 的 DiT（33.5 亿参数，单卡训不了）换成 QwenOFT 的小 MLP。

## 3. 方法的三块

| 块 | 做什么 | 标签从哪来 |
|---|---|---|
| affordance：在哪里碰、朝哪个方向 | 每类物体一张 3D 交互 map，搬到没见过的实例上，再投到画面里的每个物体 | 把示范重放一遍，统计夹爪和物体的接触。RoboCasa 的示范只有 RGB，但保存了仿真状态，可以重放出深度和分割 |
| 理解：做到哪一步、和谁交互 | 模型读最近一段画面和指令，用文字回答当前步骤和下一个交互目标 | 组合任务的示范自带逐帧的子任务标注，加仿真真值，自动生成 |
| 动作：服从计划 | 反事实训练，和 v3 一样 | 改写的动作标签 |

“学会抓一个 mug，就能抓任何 mug”落在第一块：map 按类别做，再搬到新实例。

## 4. 测什么

1. **没见过的物体实例。** 用 RoboCasa 代码里现成的实例划分，留出一部分 mug、bowl、cup 只在测试时出现。
2. **没见过的组合任务。** 最想要的结果。官方有这一档，共 16 个任务。
3. **理解本身。** 步骤和交互目标答对的比例，在留出的厨房和物体上测。
4. **服从性。** 画面不变，把计划挪到别处，看动作跟不跟。
5. **LIBERO-PRO。** 和现有结果接上。

对照：同一个骨干不加我们的方法；v3 第 6 节定的四个基线（B、D、E、F）；官方排行榜的数字只作参照。目标是同一个骨干上加和不加的差别，不是排行榜第一。最终数字按官方 50 个任务的协议出。

失败仍按 v3 第 1 节的五类归到模块，再加一类：理解答错了步骤或交互目标。

## 7. 风险和没查清的事

- **组合任务可能都在低位。** 官方排行榜上这一档的分数普遍很低，可能测不出差别。第 2 步的过关标准就是为这个设的。
- **目标不在画面里的任务。** 交互 map 指不到看不见的物体。这类任务放到最后。
- **“先分步再执行”这个思路不新。** 我们的区别是分步和交互目标都在一个 VLA 里，由 affordance 计划连接，动作被训练成服从它。这是我的判断；写论文前要查清近邻，包括排行榜上分数最高的那一类做法。
- **全量微调放不进 48 GB 的单卡。** 第 1 步按 7A 用 LoRA 绕开；主结果要不要、什么时候做全量微调，取决于多卡算力。
- **LoRA 训出的底座可能太弱。** 没有公开的 RoboCasa365 权重，底座要自己训；成功率如果在地板上，加和不加方法就比不出来。AFFO-16 先量这件事。
- **换了动作头的代价【推断】。** LIBERO 上已有的结果用的是 QwenPI。之后要么在 QwenOFT 上重做 LIBERO-PRO 那一组，要么论文里两个骨架并存。
- **第 0 步要确认的：** RoboCasa 在服务器上的无显示器渲染；留出实例的划分能不能直接用，官方排行榜有没有启用它；子任务标注是否和文档写的一致。
- **v3 的停止规则继续有效：** 扰动下预测的接触点到不了约 2 厘米，或者强基线不留提升空间，就换论点。每轮改进超过噪声的 2 倍才保留。

## 8. 不做的事

- 不用 BEHAVIOR-1K：训练和评测的开销差一个量级，资产不能导出网格，类别级的标签做不了。
- 人类厨房视频（HD-EPIC）不进主线，主线做通后再考虑。
- v3 第 7 节的其余各条继续有效：不换 OpenVLA 骨干，动作头里不加语义剪枝，不训练正逆运动学，模型不以 3D 点云为输入。
