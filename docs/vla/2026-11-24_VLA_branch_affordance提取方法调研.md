## 结论

1. **推荐路线一：类别级 3D map + 最近点搬运（我们已设计）。** 理由：直接继承现有标签，不需要新数据类型，搬运是几何的，可测。最大风险：LIBERO 里只有 mug 有 3 个网格，类别坐标系和最近点对应在形状差异大时可能失效，且验证集只有 3 种。
2. **推荐路线二：把搬运的对应关系换成描述子（NDF，其次 Robo-ABC）。** 理由：NDF 的类别级描述子能把一个示范的相对位姿搬到新实例，能补最近点的不足。最大风险：这两篇都是外挂规划器形式，只能提供标签或搬运方式，必须由我们自己把它接到训练里；要用的话，只算我们标签生成的一环。
3. 第 7 列只有 AffordanceVLA 是训练型，其余九篇都是外挂。所以“贡献是训练方法”这一条，只能靠我们自己的服从训练来满足，这些方法只负责产出标签。（推断）
4. **最小验证实验（提案，不执行）：** 用 LIBERO 的 3 种 mug 做留一：2 种做类别级 map，搬到第 3 种，和第 3 种自己的示范统计比较（Pipeline v3 已定的阈值：八成示范抓取落在前 20% 高分区，闭合轴误差中位数 < 20°）。对照：最近点搬运 vs NDF 描述子搬运。能测的只有 mug；红杯子只有 LIBERO-90 的示范，需要下载（不在本轮范围）。算力：标签与搬运只用 CPU；NDF 要在 mug 网格上训练描述子场，量级未查到。
5. 还缺：mug 之外的多网格类别；人类视频的 mug 抓取数据只在路线外，本轮未评估。

### 每条路线另外要答的

- **NDF 怎么用 5–10 个示范（全文）：** 对每个示范，在夹爪包围盒里随机采一组查询点，用夹爪位姿算出点集的描述子，对 K 个示范求平均；测试时在新点云上优化位姿，使描述子靠近平均值。夹爪朝向是这样得到的。**单视角：** 编码器训练用的是局部点云，论文说测试时通常只有局部点云；真机用了 4 个标定的深度相机融合，单相机未测，所以单视角**未查到**。**后续（只列三个）：** L-NDF（[2302.03573](https://arxiv.org/abs/2302.03573)，局部体素描述子，摘要称可迁移到没见过的形状类别，但对差别很大的物体成功率只有 10%–20%）；R-NDF（[2211.09786](https://arxiv.org/abs/2211.09786)，两个物体的相对位姿，需要一个人工标注的关键点）；EDF（[2206.08321](https://arxiv.org/abs/2206.08321)，端到端、不需要预训练，5–10 个示范）。三者的摘要都读了，未读全文。
- **Robo-ABC 的记忆库（全文）：** 来自“第一视角人类视频”，用手物接触检测器加肤色分割得到接触点，主文只写了几个数据集的引用，具体用哪一个以及量级**未查到**；记忆里有 51 个类别。抓取方向不由它给，来自 AnyGrasp。官方主页和仓库已再查一次（上表）。**RAM 是否给 3D 方向：** 是，3D 接触点加接触后方向，但不给夹爪朝向。**两者里哪个更适合产标签：** 都不能直接产“闭合轴”，RAM 稍近，因为它输出方向；但对我们的 LIBERO 杯子，两者都不如 NDF 直接。（推断）
- **VRB（全文）：** 第 7 列归入**训练**。四种范式里的作用：①离线模仿：用 affordance 模型去采数据，再做 kNN 或 BC；②探索：偏置采样，让探索集中在人类会交互的位置，coincidental success 比随机高 3–10 倍；③目标条件学习：用来产生更好的候选轨迹，按目标图像排序；④强化学习：把预测聚类成离散的 (接触点, 轨迹) 动作空间，在上面训练 DQN。这些都是在训练策略，不是 VLA。抽屉、柜门：见上表；旋钮：未测。2D 输出转 3D：深度加标定相机，见表第 2 行。

## 结论（八行）

1. **三条路线需要的数据：** 路线 1 需要物体网格或点云（我们的 LIBERO 网格可以用）和示范位姿；路线 2 只需要 RGB，加一个人类视频或示范的记忆库；路线 3 需要 RGB 和人类第一视角视频，输出 2D。
2. **最小验证实验（提案，不执行）：** LIBERO 的 3 种 mug 轮流留一，比较三种搬运：①最近点（Pipeline v3 的方案）；②NDF（用公开的 `multi_category_weights`，ShapeNet mug、bowl、bottle 预训练；LIBERO mug 网格转成点云，不需要重训）；③2D 特征对应（Robo-ABC 的 DIFT 流程，对每个网格渲染图找对应点，再投回表面）。三者都用同一份“抓取在物体坐标系里的位姿”作输入，指标沿用 Pipeline v3（八成落在前 20% 高分区，闭合轴中位误差 < 20°）。算力：CPU 或单卡即可（推断；NDF 优化开销和 DIFT 显存未查到）。
3. **推荐顺序：** 先 NDF（路线 1），再 Robo-ABC 或 RAM 的特征对应（路线 2）作对照，VRB 暂不做。
4. **路线 1 的最大风险：** NDF 论文只在 ShapeNet 形状上测；LIBERO 的 3 种 mug 形状数太少，且论文里单个示范就掉到 0.46，我们的“示范”是遥操作的抓取，不是干净的 grasp 位姿，噪声可能更大。
5. **路线 2 的最大风险：** 输出只有 2D 点，没有闭合轴；要换成我们需要的“表面点分数加闭合轴”，必须自己加一层，等于把路线 1 的东西再做一遍。
6. **路线 3 的作用：** 导师要求不局限于抓取，VRB 是十个里唯一在 cabinet、door、drawer 上有数字的；但它只有 2D，没有 mug、bowl、bottle 的抓取数字，也不给朝向，不适合现在的第一步。
7. 这些方法都是外挂的标签或搬运方式，“训练方法”的贡献仍要靠我们自己的服从训练。（推断）
