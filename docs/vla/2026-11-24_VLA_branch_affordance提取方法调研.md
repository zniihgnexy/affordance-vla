## 结论

1. **推荐路线一：类别级 3D map + 最近点搬运（我们已设计）。** 理由：直接继承现有标签，不需要新数据类型，搬运是几何的，可测。最大风险：LIBERO 里只有 mug 有 3 个网格，类别坐标系和最近点对应在形状差异大时可能失效，且验证集只有 3 种。
2. **推荐路线二：把搬运的对应关系换成描述子（NDF，其次 Robo-ABC）。** 理由：NDF 的类别级描述子能把一个示范的相对位姿搬到新实例，能补最近点的不足。最大风险：这两篇都是外挂规划器形式，只能提供标签或搬运方式，必须由我们自己把它接到训练里；要用的话，只算我们标签生成的一环。
3. 第 7 列只有 AffordanceVLA 是训练型，其余九篇都是外挂。所以“贡献是训练方法”这一条，只能靠我们自己的服从训练来满足，这些方法只负责产出标签。（推断）
4. **最小验证实验（提案，不执行）：** 用 LIBERO 的 3 种 mug 做留一：2 种做类别级 map，搬到第 3 种，和第 3 种自己的示范统计比较（Pipeline v3 已定的阈值：八成示范抓取落在前 20% 高分区，闭合轴误差中位数 < 20°）。对照：最近点搬运 vs NDF 描述子搬运。能测的只有 mug；红杯子只有 LIBERO-90 的示范，需要下载（不在本轮范围）。算力：标签与搬运只用 CPU；NDF 要在 mug 网格上训练描述子场，量级未查到。
5. 还缺：mug 之外的多网格类别；人类视频的 mug 抓取数据只在路线外，本轮未评估。
