1 · 总览：从两张图到 8 步动作

一次抓取拆成三件事：抓哪个物体（M1 语义门控）、抓哪里、朝什么方向（M2 交互 map）、手怎么动（动作头，只负责服从计划）。VLM 全程冻结；训练的只有 map 头和动作头上的少量参数。

2.3 M2 交互 map 头 已实现（8×8 版 g1） 训练

代码：affordance_vla/heads/plan_grid.py。参数 7.89M；g1 训练 2500 步，学习率 3e-4，宽度 512。

H=\sum_{\ell=1}^{36}\operatorname{softmax}(m)_\ell\,h^{(\ell)},\qquad X=W_{2560\to512}\,\mathrm{LN}(H)
Z=\mathrm{Enc}_{2\times}\big([\,q;\,X\,]\big)\quad(\text{512 维，8 头，FFN 2048，pre-norm，双向，无 dropout})
\big[\ell_c,\ \tilde o_c,\ \hat z_c\big]=W_{512\to4}\,Z_{\text{cell}(c)},\qquad o_c=\sigma(\tilde o_c)\in[0,1]^2,\quad c=1,\dots,64
\big[\text{event}\in\mathbb R^{3},\ \tilde a\big]=\mathrm{MLP}_{512\to512\to6}(\mathrm{LN}(Z_q)),\qquad a=\tilde a/\lVert\tilde a\rVert
  • q 是一个学到的汇总 token，放在序列最前面；Z_{\text{cell}(c)} 是智能体视角第 c 个图像 token 在序列里的位置（按行排）。腕部视角的 token 也在序列里，但不出格子。
  • 事件分三类：没有、抓、放。深度 \hat z_c 的单位是 10 cm，以 1 m 为零点。

计划中（E2、E4） 同一个头扩展成 v3 的交互 map：

  • 交互分数 I_c=\sigma(\ell_c) 对画面里所有物体都画，不只是点名的那个。
  • 每格加方向场 (\cos2\theta_c,\ \sin2\theta_c)：夹爪闭合方向在图上的角度，转 180° 算同一种抓法。读出时 \theta_c=\tfrac12\operatorname{atan2}(\sin2\theta_c,\cos2\theta_c)。
  • 更细的特征：先用 ViT 合并之前的 16×16 块（不加新模型），不够再加 DINOv2。

2.4 M1 语义门控 计划中（E2）

s_c=\cos\!\big(\mathrm{pool}_{k\in\text{指令}}\,h^{(\ell)}_k,\ h^{(\ell)}_{\text{cell}(c)}\big),\qquad \mathrm{pool}\in\{\text{平均},\ \text{最大}\}
w_c=\frac{e^{\alpha s_c}}{\sum_{c'}e^{\alpha s_{c'}}},\qquad T_c=w_c\cdot I_c,\qquad \alpha_{\text{init}}=0

α 从 0 开始，所以刚开始 w 是均匀的，等于没有语义。目标损失只更新门控，"抓哪个"和"抓哪里"分开学。

E1 的结果（冻结 VLM，不训练，74 个首帧：Object 40，Spatial 34）：相似度图的峰值很少落在点名物体上，随机水平约 5%（点名物体平均只占 3.3 格）。

逐物体看（每个物体区域里的平均相似度，最高的是不是点名物体；这更接近门控的用法，因为交互分数只在物体上）：

\bar s_k=\frac{\sum_c \mathrm{cov}_{k,c}\,s_c}{\sum_c \mathrm{cov}_{k,c}},\qquad \text{命中}=\big[\arg\max_k \bar s_k=\text{点名物体}\big]
首帧随机水平整句指令只用物体名
LIBERO-Object（40 帧）0.140.15–0.200.23–0.30
LIBERO-Spatial（34 帧）0.200.35–0.410.50–0.62

Spatial 的目标是两只一样的碗之一：相似度能找到"碗"，分不清是哪一只（随便挑一只就有一半）。层和合并方式之间的差别在一两个标准差以内。同样的首帧上，训练过的 g1 在 Object 上只认错 3/40（任务扰动 20/20 都在 2 cm 内；位置扰动 6/20 偏了超过 2 cm），在没训练过的 Spatial 上只有 3/34 落在点名的碗上。

决定（11-20）：按 v3 M1 的预案，E2 的门控加一个小的可学习投影，先用指令 token 求平均、最后一层：

s_c=\cos\!\big(P_t\,\mathrm{mean}_{k\in\text{指令}}h^{(36)}_k,\ P_x\,h^{(36)}_{\text{cell}(c)}\big)\qquad(P_t,P_x\text{ 的大小待定})

E2 的离线评测加上 LIBERO-PRO Spatial 的首帧（项目负责人同意）：Object 上 g1 很少认错物体，门控的作用要在两只一样的碗上才看得出来。为此 map 头的训练数据提前加入 dataset_spatial，对照是同样数据、不加门控的 g1。

2.5 解码成 3D 接触点 已实现

c^*=\arg\max_c \ell_c\quad(\text{计划中：}\arg\max_c T_c),\qquad u=(\mathrm{col}(c^*)+o_x)\cdot28,\quad v=(\mathrm{row}(c^*)+o_y)\cdot28
d=\operatorname{clip}\big(1\,\mathrm m+0.1\,\mathrm m\cdot\hat z_{c^*},\ 0.2,\ 3\big),\qquad p_{\text{world}}=T_{\text{cam}\to\text{world}}\big(d\,K^{-1}[u',v',1]^\top\big)

K 和 T 是这台固定相机的标定，从仿真日志读。它不是物体的真值，测试时可以用。

计划中 夹爪朝向 = 接近方向 a + 峰值格子上的闭合方向 \theta_{c^*}。物体朝向放在第二阶段：把这类物体的 3D 标准 map 放到预测的位置，绕竖直轴每 10° 转一档，投到画面上和预测的 map 比较，取最吻合的角度：

\psi^*=\arg\max_{\psi\in\{0^\circ,10^\circ,\dots,350^\circ\}}\ \mathrm{overlap}\big(\Pi(R_z(\psi)\,\mathcal M),\ \hat I\big)+\lambda\,\mathrm{agree}\big(\Pi(R_z(\psi)\,\mathcal M),\ \hat\theta\big)

λ 和两项的具体定义还没定。

3 · 训练

3.1 map 头的标签

已实现：g1 的标签 ORACLE 接触点 = 物体在仿真里的位置 + 示范里这个物体的平均抓取偏移（放的时候是容器位置 + 平均放置偏移）。接近方向 = 这个物体所有示范在事件前 10 步运动方向的平均。投到画面上得到格子、偏移、深度。同一帧也可以换成"点名另一个物体"的指令，目标换成那个物体的抓取点，不需要新示范。

已实现：L2，每个网格一张 3D 标准 map（plan/interaction_labels.py，ec1c792）

  1. 表面：可视网格上按面积采 3000 个点，带法向 n，在物体自己的坐标系里。
  2. 抓取：仿真报告"抓住"的上升沿，并且持续 ≥ 5 步（0.25 s）。ORACLE 用仿真里的物体位姿把夹爪换到物体坐标系：
g=R_o^\top(p_{ee}-p_o),\qquad y=R_o^\top R_{ee}\,e_{\text{close}}\quad(\text{闭合轴，是一条线，不分正反})
w_g(x)=\exp\!\Big(-\tfrac12\big(\tfrac{d_\perp}{1.2\,\mathrm{cm}}\big)^2\Big)\cdot\operatorname{clip}\!\Big(\tfrac{|n\cdot y|-0.3}{0.7},0,1\Big)\cdot\mathbf{1}\big[\,|(x-g)\cdot y|\le5\,\mathrm{cm}\,\big]
d_\perp=\big\lVert (x-g)-((x-g)\cdot y)\,y\big\rVert,\qquad S(x)=\frac{\sum_g w_g(x)}{\max_{x'}\sum_g w_g(x')}
M(x)=\sum_g w_g(x)\,y_g y_g^\top,\qquad \text{axis}(x)=\text{最大特征向量},\qquad A(x)=\frac{3\lambda_{\max}/\operatorname{tr}M-1}{2}\in[0,1]

y y^\top 对 y 和 -y 一样，所以转 180° 的两次抓取会叠加，不会抵消。A=1 表示这个点上所有抓取沿同一条线，A=0 表示方向均匀散开。

投到一帧上（每个物体都投）：X=R_o x+p_o，按镜像投到 256 的日志图上。保留的点要满足两条：落在这个物体的分割像素上；深度不超过同一 4×4 像素块里最近点 1.5 cm（去掉被物体自己挡住的背面）。

\text{score}_c=\max_{x\in c}S(x),\qquad \text{dir}_c=\frac{\sum_{x\in c}S(x)\,[\cos2\theta_x,\ \sin2\theta_x]}{\sum_{x\in c}S(x)}

\theta_x 是把 1 cm 长的闭合轴投到图上后的角度。结果：LIBERO-Object 10 类、LIBERO-10 10 类都有 map，Object 的 10 类里有 9 类，八成以上的抓取闭合轴落在同一组（彼此 20° 以内）。

计划中：L2c，类别级 map（第五轮） 同一类的不同网格对齐到一个类别坐标系。原点在底面中心 b；高度 h 和水平半径 \rho 都归一化到 1；绕竖直轴转 \varphi，让把手朝 +x：

\tilde x=\operatorname{diag}\!\big(\tfrac1\rho,\tfrac1\rho,\tfrac1h\big)\,R_z(\varphi)\,(x-b)

所有网格的抓取在 \tilde x 里叠成一张 map。新网格的每个点取最近的类别 map 点的分数和闭合轴。

高矮胖瘦测试集：网格乘 S=\operatorname{diag}(s_x,s_y,s_z)，档位为高 ×0.8、×1.3，粗 ×0.8、×1.2，再加两种组合。闭合轴按法向的规则变换：

x'=Sx,\qquad y'=\frac{S^{-1}y}{\lVert S^{-1}y\rVert}

检查（留一种杯子）：留出的杯子自己的示范抓取，八成以上落在搬来的 map 分数前 20% 的表面上；闭合轴误差中位数小于 20°。

计划中：L1 抓取那一刻的夹爪位姿加物体分割图，直接给逐像素的"接触区域 + 闭合方向"。精确版借 AROS 的交互面，用夹爪网格和物体网格算。

3.2 map 头的损失

\mathcal L_{\text{map}}=\mathrm{CE}(\text{event})+\mathrm{CE}(\ell,\ c^{\star})+10\,\mathrm{Huber}_{0.1}(o_{c^\star})+10\,\mathrm{Huber}_{0.2}(\hat z_{c^\star})+0.5\,(1-\hat a\cdot a)

事件损失每帧都算；接近方向在有事件的帧算；格子、偏移、深度只在有事件、并且接触点落在画面里时算。Huber 的阈值是格子的 1/10（约 1 cm）和 2 cm。已实现

\mathcal L_{\text{v3}}=\underbrace{\mathrm{BCE}(I,\ \text{所有物体的标签})}_{\text{交互分数}}+\underbrace{\mathrm{CE}(T,\ \text{点名物体的标签分布})}_{\text{只更新 M1}}+\underbrace{\big\lVert\widehat{\text{dir}}-\text{dir}\big\rVert^2_{\text{接触区域内}}}_{\text{方向场}}+\mathrm{Huber}(\hat z)+\text{事件、接近方向}

计划中 各项的权重还没定。点名物体有几种可行抓法时，标签是一个分布。

3.4 动作头的损失 已实现

x_t=(1-t)\,\varepsilon+t\,a,\qquad t=\frac{0.999-u}{0.999},\ \ u\sim\mathrm{Beta}(1.5,\,1),\qquad \varepsilon\sim\mathcal N(0,I)
\mathcal L_{\text{flow}}=\frac{\sum m\odot\lVert\hat v(x_t,t,f)-(a-\varepsilon)\rVert^2}{\sum m},\qquad \hat a=x_t+(1-t)\,\hat v
\mathcal L=\mathcal L_{\text{flow}}+0.2\,\mathcal L_{\text{path}},\qquad \mathcal L_{\text{path}}=\mathrm{Huber}_{0.5\,\text{cm}}\Big(p_0+s\textstyle\sum_{k\le j}\hat a_{k,xyz},\ \ \text{目标路径}_j\Big)

m 是哪些动作维有标签的掩码。\hat a 是一步估出的干净动作，\mathcal L_{\text{path}} 比较它要走的路径和目标路径（单位 cm）。s10 的设置：4000 步，学习率 2e-4，454 条示范、56,852 帧，监督方式 actions（改写后的平移直接进流匹配损失）。

离线首帧检查（每次改了 map 头都先做）

  • 认对物体率：门控后的峰值落在点名物体的分割区域里的比例。
  • 所有物体的 map：每个物体自己区域里的峰值，是否落在它的接触区域里。
  • 位置误差：沿视线方向和垂直视线方向分开算，单位 cm。
  • 闭合方向误差：\min(|\theta-\hat\theta|,\ 180^\circ-|\theta-\hat\theta|)，真值来自 L2。
  • 物体朝向误差（第二阶段）：按物体的对称性取最小。
