1 · Overview: from two images to an 8-step action

A grasp splits into three parts: which object (M1 semantic gate), where and in which direction (M2 interaction map), how to move (action head, which only obeys the plan). The VLM stays frozen; only the map head and a few action-head parameters are trained.

2.3 M2 interaction map head implemented (8×8 g1) trained

Code: affordance_vla/heads/plan_grid.py. 7.89M parameters; g1 trained for 2500 steps, learning rate 3e-4, width 512.

H=\sum_{\ell=1}^{36}\operatorname{softmax}(m)_\ell\,h^{(\ell)},\qquad X=W_{2560\to512}\,\mathrm{LN}(H)
Z=\mathrm{Enc}_{2\times}\big([\,q;\,X\,]\big)\quad(\text{512-d, 8 heads, FFN 2048, pre-norm, bidirectional, no dropout})
\big[\ell_c,\ \tilde o_c,\ \hat z_c\big]=W_{512\to4}\,Z_{\text{cell}(c)},\qquad o_c=\sigma(\tilde o_c)\in[0,1]^2,\quad c=1,\dots,64
\big[\text{event}\in\mathbb R^{3},\ \tilde a\big]=\mathrm{MLP}_{512\to512\to6}(\mathrm{LN}(Z_q)),\qquad a=\tilde a/\lVert\tilde a\rVert
  • q is a learned summary token at the start of the sequence; Z_{\text{cell}(c)} is the output at agent-view image token c (row by row). Wrist-view tokens are in the sequence but output no cells.
  • Three event classes: none, grasp, release. Depth \hat z_c is in units of 10 cm, zero at 1 m.

planned (E2, E4) the same head extended to the v3 interaction map:

  • interaction score I_c=\sigma(\ell_c) drawn for every object in view, not only the named one.
  • a direction field per cell (\cos2\theta_c,\ \sin2\theta_c): the image angle of the gripper closing axis, 180°-symmetric; read out as \theta_c=\tfrac12\operatorname{atan2}(\sin2\theta_c,\cos2\theta_c).
  • finer features: first the ViT patches before merging (16×16, no new model), then DINOv2 if needed.

2.4 M1 semantic gate planned (E2)

s_c=\cos\!\big(\mathrm{pool}_{k\in\text{instr}}\,h^{(\ell)}_k,\ h^{(\ell)}_{\text{cell}(c)}\big),\qquad \mathrm{pool}\in\{\text{mean},\ \text{max}\}
w_c=\frac{e^{\alpha s_c}}{\sum_{c'}e^{\alpha s_{c'}}},\qquad T_c=w_c\cdot I_c,\qquad \alpha_{\text{init}}=0

α starts at 0, so w is uniform at first: no semantics. The target loss updates only the gate, so "which object" and "where" are learned separately.

E1 result (frozen VLM, no training, 74 first frames: Object 40, Spatial 34): the similarity maps rarely peak on the named object; chance is about 5% (the named object covers 3.3 cells on average).

In Spatial the target is one of two identical bowls: similarity finds "a bowl" but not which one (either bowl gives half). On the same frames the trained g1 picks the wrong object in only 3/40 Object frames (task perturbation 20/20 within 2 cm; position perturbation 6/20 off by more than 2 cm) and lands on the named bowl in only 3/34 Spatial frames, a suite it was not trained on.

Decision (11-20): as planned for M1 in v3, the E2 gate gets a small learned projection, starting with the mean of the instruction tokens at the last layer:

s_c=\cos\!\big(P_t\,\mathrm{mean}_{k\in\text{instr}}h^{(36)}_k,\ P_x\,h^{(36)}_{\text{cell}(c)}\big)\qquad(\text{size of }P_t,P_x\text{ open})

E2's offline check adds LIBERO-PRO Spatial first frames (agreed by the project lead): on Object g1 rarely picks the wrong object, so the gate can only show its effect on the two identical bowls. The map head therefore trains with dataset_spatial from E2 on; the control is g1 on the same data without the gate.

2.5 Decoding to a 3D contact implemented

c^*=\arg\max_c \ell_c\quad(\text{planned: }\arg\max_c T_c),\qquad u=(\mathrm{col}(c^*)+o_x)\cdot28,\quad v=(\mathrm{row}(c^*)+o_y)\cdot28
d=\operatorname{clip}\big(1\,\mathrm m+0.1\,\mathrm m\cdot\hat z_{c^*},\ 0.2,\ 3\big),\qquad p_{\text{world}}=T_{\text{cam}\to\text{world}}\big(d\,K^{-1}[u',v',1]^\top\big)

K and T are the calibration of this fixed camera, read from the simulator log; they are not object ground truth and may be used at test time.

planned gripper orientation = approach direction a + the closing direction at the peak cell \theta_{c^*}. Object orientation comes in phase two: place the category's 3D canonical map at the predicted position, rotate it about the vertical axis in 10° steps, project it and compare with the predicted map; take the best angle:

\psi^*=\arg\max_{\psi\in\{0^\circ,10^\circ,\dots,350^\circ\}}\ \mathrm{overlap}\big(\Pi(R_z(\psi)\,\mathcal M),\ \hat I\big)+\lambda\,\mathrm{agree}\big(\Pi(R_z(\psi)\,\mathcal M),\ \hat\theta\big)

λ and the exact definition of both terms are still open.

2.6 Plan vector and plan hold implemented

Code: affordance_vla/plan/plan_input.py, plan/plan_hold.py. r is the contact minus the current gripper position.

f=\Big[\ \tfrac{r}{0.10\,\mathrm m},\ \ \tanh\!\big(\tfrac{r}{0.02\,\mathrm m}\big),\ \ a,\ \ e\ \Big]\in\mathbb R^{10},\qquad e=\begin{cases}+1&\text{grasp}\\-1&\text{release}\end{cases},\quad\text{no event: }f=0
dimscontentrole
0–2r / 10 cmcoarse: not saturated far away
3–5tanh(r / 2 cm)fine: resolves the last centimetres, saturates far away
6–8approach direction a (unit vector)where the gripper comes from
9event e+1 grasp, −1 release
10–15target orientation (relative to the current gripper, 6D)planned; E3 decides
  • Plan hold: the contact is in world coordinates and stays fixed until the event, so it is predicted once per phase. Each query only recomputes r. The event is complete after 5 consecutive matching gripper commands ("close" for a grasp, "open" for a release); the next query predicts a new plan.
  • Query rate: the action head returns 8 steps, all executed before the next query.
  • ORACLE control "oracle plan": contact = simulator object position + the mean grasp offset of that object's demonstrations. Used only as an upper bound.

2.7 Action head implemented

Code: starVLA LayerwiseFM_ActionHeader.py, cross_attention_dit.py; our additions in affordance_vla/heads/plan_policy.py.

\mathrm{tok}_j=W_3\,\mathrm{swish}\!\big(W_2\,[\,W_1x_{t,j};\ \mathrm{sin}(\tau)\,]\big)+\mathrm{pos}_j+\mathrm{MLP}_{\text{plan}}(f),\qquad j=1,\dots,8
\mathrm{tok}\leftarrow\mathrm{tok}+\mathrm{CrossAttn}\big(\mathrm{AdaLN}(\mathrm{tok},\tau),\ h^{(i)}\big),\quad \mathrm{tok}\leftarrow\mathrm{tok}+\mathrm{FFN}(\mathrm{LN}(\mathrm{tok})),\qquad i=1,\dots,36
\hat v=\mathrm{MLP}_{2560\to1024\to7}(\mathrm{tok}),\qquad x_{k+1}=x_k+\tfrac14\,\hat v(x_k,\tau_k),\quad \tau_k=\lfloor 1000\cdot k/4\rfloor,\ \ x_0\sim\mathcal N(0,I)
  • W_1: 7→2560; W_2: 5120→2560; W_3: 2560→2560; \tau is the sinusoidal encoding of the time bucket (1000 buckets).
  • Each block cross-attends with 40 heads × 64 dims; K, V are all tokens of LLM layer i (image and text, with the attention mask). FFN 2560→10240→2560, GELU.
  • The 32 learnable tokens of the official head cannot see the action tokens, so they are not used; the proprioceptive state is not an input.
  • plan encoder \mathrm{MLP}_{\text{plan}}: 10→512→512→2560, SiLU, last layer zero-initialised, so before training it equals the official policy.

2.8 Execution implemented

The 8 × 7 action is de-normalised with dataset statistics: Δposition 3, Δrotation 3, gripper 1 (policy: 0 = close, 1 = open). robosuite's OSC controller computes joint torques at 20 Hz. No forward or inverse kinematics are trained.

3 · Training

3.1 Map-head labels

implemented: g1 labels ORACLE contact = simulator object position + the mean grasp offset of that object's demonstrations (release: container position + mean place offset). Approach = the mean motion direction over the 10 steps before the event, over all demos of that object. Projected to a cell, an offset and a depth. A frame can also get an instruction naming another object, with that object's grasp point as target, without new demonstrations.

implemented: L2, one 3D canonical map per mesh (plan/interaction_labels.py, ec1c792)

  1. Surface: 3000 points sampled by area on the visual meshes, with normals n, in the object's own frame.
  2. Grasps: rising edge of the simulator's "grasped" flag, held ≥ 5 steps (0.25 s).ORACLE the simulator object pose maps the gripper into the object frame:
g=R_o^\top(p_{ee}-p_o),\qquad y=R_o^\top R_{ee}\,e_{\text{close}}\quad(\text{closing axis: a line, sign-free})
w_g(x)=\exp\!\Big(-\tfrac12\big(\tfrac{d_\perp}{1.2\,\mathrm{cm}}\big)^2\Big)\cdot\operatorname{clip}\!\Big(\tfrac{|n\cdot y|-0.3}{0.7},0,1\Big)\cdot\mathbf{1}\big[\,|(x-g)\cdot y|\le5\,\mathrm{cm}\,\big]
d_\perp=\big\lVert (x-g)-((x-g)\cdot y)\,y\big\rVert,\qquad S(x)=\frac{\sum_g w_g(x)}{\max_{x'}\sum_g w_g(x')}
M(x)=\sum_g w_g(x)\,y_g y_g^\top,\qquad \text{axis}(x)=\text{top eigenvector},\qquad A(x)=\frac{3\lambda_{\max}/\operatorname{tr}M-1}{2}\in[0,1]

y y^\top is the same for y and -y, so two grasps 180° apart add up instead of cancelling. A=1 means all grasps at this point lie along one line; A=0 means the directions spread evenly.

Projection to a frame (every object): X=R_o x+p_o, projected with mirroring onto the 256 log image. A point is kept if it falls on this object's segmentation pixels and its depth is within 1.5 cm of the nearest point in the same 4×4-pixel block (drops the self-occluded back).

\text{score}_c=\max_{x\in c}S(x),\qquad \text{dir}_c=\frac{\sum_{x\in c}S(x)\,[\cos2\theta_x,\ \sin2\theta_x]}{\sum_{x\in c}S(x)}

\theta_x is the image angle of the closing axis projected over 1 cm. Result: maps for LIBERO-Object (10 categories) and LIBERO-10 (10); in 9 of the 10 Object categories, over 80% of the closing axes fall in one group (within 20° of each other).

planned: L2c, category-level map (round 5) The meshes of one category are aligned to a category frame: origin at the bottom centre b; height h and horizontal radius \rho normalised to 1; rotated about the vertical by \varphi so the handle points to +x:

\tilde x=\operatorname{diag}\!\big(\tfrac1\rho,\tfrac1\rho,\tfrac1h\big)\,R_z(\varphi)\,(x-b)

The grasps of all meshes are summed in \tilde x into one map. Each point of a new mesh takes the score and axis of the nearest category-map point.

Tall/short/fat/thin test set: meshes multiplied by S=\operatorname{diag}(s_x,s_y,s_z), with height ×0.8, ×1.3 and width ×0.8, ×1.2, plus two combinations. Closing axes transform like normals:

x'=Sx,\qquad y'=\frac{S^{-1}y}{\lVert S^{-1}y\rVert}

Check (leave one mug out): over 80% of the held-out mug's own demo grasps fall on the top-20% surface of the transferred map; median axis error below 20°.

planned: L1 the gripper pose at the grasp plus the object segmentation gives a per-pixel "contact region + closing direction" directly. A finer version uses AROS's interaction surface between the gripper and object meshes.

3.2 Map-head losses

\mathcal L_{\text{map}}=\mathrm{CE}(\text{event})+\mathrm{CE}(\ell,\ c^{\star})+10\,\mathrm{Huber}_{0.1}(o_{c^\star})+10\,\mathrm{Huber}_{0.2}(\hat z_{c^\star})+0.5\,(1-\hat a\cdot a)

The event loss is computed on every frame, the approach on frames with an event, cell, offset and depth only on frames with an event whose contact is in view. Huber thresholds: 1/10 of a cell (about 1 cm) and 2 cm.implemented

\mathcal L_{\text{v3}}=\underbrace{\mathrm{BCE}(I,\ \text{all-object labels})}_{\text{interaction score}}+\underbrace{\mathrm{CE}(T,\ \text{named-object label distribution})}_{\text{updates M1 only}}+\underbrace{\big\lVert\widehat{\text{dir}}-\text{dir}\big\rVert^2_{\text{in contact regions}}}_{\text{direction field}}+\mathrm{Huber}(\hat z)+\text{event, approach}

planned the weights of the terms are not set yet. When the named object has several feasible grasps, the label is a distribution.

3.3 Action head: counterfactual samples implemented (s10)

Same frame, different plan, and the action label is rewritten to match, so the action head learns "go where the plan is" instead of memorising scenes.

  • Rotation follows the demo and is supervised only before the contact; the gripper command comes at the demo's closing distance from the contact.
  • Frames within 3 cm of the contact get no counterfactual.

3.4 Action-head loss implemented

x_t=(1-t)\,\varepsilon+t\,a,\qquad t=\frac{0.999-u}{0.999},\ \ u\sim\mathrm{Beta}(1.5,\,1),\qquad \varepsilon\sim\mathcal N(0,I)
\mathcal L_{\text{flow}}=\frac{\sum m\odot\lVert\hat v(x_t,t,f)-(a-\varepsilon)\rVert^2}{\sum m},\qquad \hat a=x_t+(1-t)\,\hat v
\mathcal L=\mathcal L_{\text{flow}}+0.2\,\mathcal L_{\text{path}},\qquad \mathcal L_{\text{path}}=\mathrm{Huber}_{0.5\,\text{cm}}\Big(p_0+s\textstyle\sum_{k\le j}\hat a_{k,xyz},\ \ \text{target path}_j\Big)

m masks the action dims that have labels. \hat a is the one-step estimate of the clean action; \mathcal L_{\text{path}} compares its path with the target path (in cm). s10: 4000 steps, learning rate 2e-4, 454 demos, 56,852 frames, supervision "actions" (the rewritten translation enters the flow-matching loss directly).

Offline first-frame check (first, after every change to the map head)

  • object ID rate: share of gated peaks inside the named object's segmentation.
  • all-object map: whether each object's own peak lies in its contact region.
  • position error: along and across the viewing direction, in cm.
  • closing-direction error: \min(|\theta-\hat\theta|,\ 180^\circ-|\theta-\hat\theta|), ground truth from L2.
  • object orientation error (phase two): minimum over the object's symmetries.
